max_new_tokens - Maximum number of new tokens the model can generate. Controls response length.
max_length - Maximum total length (input + output). Usually replaced by `max_new_tokens`.
temperature - Controls randomness and creativity. Lower values produce more focused answers; higher values produce more diverse answers.
do_sample - Enables random sampling. When disabled, the model always chooses the most likely next token.
top_k - Restricts token selection to the K most probable tokens. Lower values make outputs more focused.
top_p - Uses nucleus sampling. Selects tokens from the smallest set whose cumulative probability reaches the specified threshold.
repetition_penalty - Reduces repetition of words and phrases. Values greater than 1 discourage repeated text.
num_return_sequences - Number of different responses generated for the same prompt.
eos_token_id - End-of-sequence token. When generated, the model stops producing text.
pad_token_id - Padding token used to make sequences the same length during batch processing.

For most RAG systems:
* Low temperature → more factual answers.
* Moderate `max_new_tokens` → prevents overly long responses.
* Small repetition penalty → reduces repeated text.
* `top_p` around 0.9 → balances accuracy and diversity.
